## 🛠 the pattern

```text
one operator
  ├── one workstation
  ├── one runtime (Orange³)
  ├── one covenant (§4A no-SaaS)
  ├── one publishing pipeline (AI Bookmaker)
  └── one broadcast (atomeons.com)

no employees · no investors · no SaaS · no telemetry · no lock-in
```

**§4A no-SaaS covenant**: every AtomEons product runs locally, free, forever. No subscription tier. No "pro" upsell. No "cloud" fallback that becomes the actual product. If it can only run on our servers, we didn't build it right.
